Privacy Policy · 내업로더 · 시행일 Effective date: 2026-11-16

1. 이 프로그램에 대해 · About

내업로더(이하 "프로그램")는 운영자가 자신의 유튜브 채널에 영상을 올리기 위해 만든 개인용 데스크톱 프로그램이며, YouTube API 서비스를 사용합니다.

내업로더 ("the app") is a personal desktop app made by its operator to upload videos to their own YouTube channels. It uses YouTube API Services.

2. 이용하는 정보 · Data accessed

구글 로그인으로 사용자가 허용한 범위 안에서 다음 정보만 이용합니다.

  • 유튜브 채널 기본 정보(채널 이름, 구독자 수, 조회수, 영상 수)
  • 사용자가 올린 영상의 목록과 처리 상태
  • 재생목록 목록
  • 사용자가 프로그램에 직접 넣은 영상 파일, 제목, 설명, 태그, 썸네일, 자막

Within the permissions the user grants through Google sign-in, the app only uses: basic channel information (name, subscriber/view/video counts), the list and processing status of the user's uploaded videos, the user's playlists, and the video files and metadata (titles, descriptions, tags, thumbnails, captions) the user adds to the app.

3. 이용 목적 · How data is used

사용자가 요청한 영상 업로드, 공개 예약, 썸네일·자막·재생목록 등록, 업로드 상태 확인에만 사용합니다. 광고, 분석, 판매 목적으로 사용하지 않습니다.

Data is used only to perform what the user asks for: uploading videos, scheduling publication, setting thumbnails, captions and playlists, and checking upload status. It is not used for advertising, analytics or sale.

4. 저장 · Storage

로그인 정보(구글 액세스 토큰)와 업로드 목록은 사용자의 컴퓨터에만 저장됩니다. 운영자의 서버나 외부 서비스로 보내지 않습니다. 정보는 구글(YouTube API)과 직접 주고받습니다.

Sign-in tokens and the upload queue are stored only on the user's own computer. They are not sent to any server operated by the developer or to any third party. The app communicates directly with Google (YouTube API).

5. 제3자 제공 · Sharing

사용자 정보를 다른 사람이나 회사에 제공하지 않습니다. 프로그램이 구글 API에서 받은 정보의 사용과 전송은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

User data is not shared with any other person or company. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. 삭제와 권한 철회 · Deletion and revoking access

  • 프로그램의 관리 → 이 채널 연결 삭제를 하거나 프로그램 폴더의 data 폴더를 지우면 컴퓨터에 저장된 정보가 삭제됩니다.
  • 구글 계정의 서드파티 앱 및 서비스에서 언제든 권한을 철회할 수 있습니다.

Removing the channel in the app or deleting the app's data folder deletes all locally stored data. Access can be revoked at any time from Google Account › Third-party apps & services.

7. 관련 약관 · Related terms

이 프로그램을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. 구글의 정보 처리 방식은 Google 개인정보처리방침을 따릅니다.

By using the app, users agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

8. 변경 · Changes

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다.

Any changes will be posted on this page with a new effective date.
